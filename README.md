# minh27ten.github.io

Personal developer portfolio and live GitHub REST API showcase for [minh27ten](https://github.com/minh27ten).

🌐 **Live Site:** [https://minh27ten.github.io](https://minh27ten.github.io)

## Overview

This repository hosts the personal developer portfolio website deployed via GitHub Pages.

### Features
- **Portfolio Showcase**: Highlights key projects including CircuitLab, Mo_phong_mach_dien, hust-control-studio, and gemini-quota-estimator.
- **GitHub REST API Integration**: Dynamically queries the public GitHub REST API (`https://api.github.com/users/minh27ten/repos`) to display real-time repository statistics, stars, forks, and recent activity.
- **Responsive Design**: Fast, modern, responsive HTML5 and CSS layout.
